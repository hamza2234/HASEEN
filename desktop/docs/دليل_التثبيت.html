خطوات التثبيت

  1. نزّل ملف التثبيت
    ستجد ملفاً واحداً باسم HybridPSOGA-Setup-1.0.0.exe. انسخه إلى الحاسوب الذي تريد تشغيل البرنامج عليه. لا تحتاج إلى أي شيء آخر: لا Python ولا MATLAB ولا اتصال بالإنترنت.
  2. ابدأ التثبيت
    انقر نقراً مزدوجاً على HybridPSOGA-Setup-1.0.0.exe. إذا طلب ويندوز الإذن فاختر نعم. ستُفتح نافذة التثبيت.
  3. صفحة الترحيب
    اقرأ المقدمة المختصرة ثم اضغط Next.
  4. صفحة الترخيص
    اقرأ الترخيص (البرنامج للاستخدام الأكاديمي في مناقشة الرسالة) ثم اختر I accept the agreement ثم Next.
  5. اختر المجلد
    اترك المجلد المقترح كما هو، أو اختر مجلداً آخر. ثم اضغط Next.
  6. اختر الاختصارات
    اترك خيار Create a desktop shortcut محدَّداً. ثم اضغط Next.
  7. جاهز للتثبيت
    اضغط Install. يستغرق التثبيت أقل من دقيقة.
  8. إنهاء
    اترك خيار Launch the application محدَّداً ثم اضغط Finish. سيفتح البرنامج.
  9. اختر اللغة
    في الشريط الجانبي في الأسفل اختر العربية أو English. ستتغيّر الواجهة كاملة، بما في ذلك اتجاه التخطيط.
  10. ابدأ الاستخدام
    اذهب إلى فحص بريد والصق نص بريد، أو فحص رابط واكتب عنوان موقع. ستحصل على القرار ونسبة الثقة والسمات التي بنى عليها القرار.

Installation guide, step by step

Disk spaceabout 900 MB after installation

Installation steps

  1. Download the setup file
    You received one file: HybridPSOGA-Setup-1.0.0.exe. Copy it to the computer where the program should run. Nothing else is needed — no Python, no MATLAB, no internet connection.
  2. Start the installer
    Double-click HybridPSOGA-Setup-1.0.0.exe. If Windows asks for permission, click Yes. The setup wizard opens.
  3. Welcome page
    Read the short introduction and click Next.
  4. Licence page
    Read the license (the program is for academic use in the thesis defense) and click I accept the agreement, then Next.
  5. Choose the folder
    Keep the suggested folder, or choose another one. Click Next.
  6. Choose the shortcuts
    Leave Create a desktop shortcut ticked. Click Next.
  7. Ready to install
    Click Install. Installation takes under a minute.
  8. Finish
    Leave Launch the application ticked and click Finish. The program opens.
  9. Choose the language
    In the sidebar at the bottom, choose العربية or English. The whole interface switches, including the direction of the layout.
  10. Use it
    Go to Check email and paste an email, or Check URL and type a website address. You get a verdict, the confidence, and the attributes behind the decision.

Uninstalling

Open Settings → Apps → Installed apps, find Hybrid PSO-GA Feature Selection System and click Uninstall. No internet connection is needed at any point, before or after installation.
